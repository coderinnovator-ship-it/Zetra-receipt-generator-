# 📄 Professional Receipt Generator

A simple, elegant web-based receipt generator that creates professional PDF receipts instantly. Perfect for small businesses, freelancers, and anyone who needs to generate receipts quickly.

## ✨ Features

- 🎨 Modern, user-friendly interface
- 📱 Fully responsive design
- 💼 Professional PDF output
- ➕ Add multiple items per receipt
- 🔢 Automatic total calculation
- 👁️ Live preview before download
- 💾 No data storage - completely private
- 🚀 Works offline after initial load

## 🛠️ How to Use

1. Open `index.html` in your browser
2. Enter your company name
3. Enter customer name or email
4. Add item details (name, quantity, price)
5. Click "Add Item" to add to receipt
6. Repeat for multiple items
7. Click "Download Receipt PDF" to generate

## 💻 Installation

### Option 1: Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/receipt-generator.git
   ```
2. Open `index.html` in your web browser
3. That's it! No installation or dependencies required.

### Option 2: Deploy on GitHub Pages
1. Fork this repository
